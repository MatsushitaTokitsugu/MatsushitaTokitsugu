# Kasanegi

Founder of **[Kasanegi](https://kasanegi.com/en/)**, an R&D studio in Osaka, Japan, built on one idea: use AI to find new value in data that already exists.

- **Research** — searching Japan-wide terrain for undiscovered meteorite craters with machine learning · [kasanegi.com/en/research](https://kasanegi.com/en/research/)
- **kasanegi** — two language editions of the same manga, layered page by page on your device · [demo](https://kasanegi.com/demo/)
- **Data APIs** — Japanese public data as tools for AI agents, over MCP and OpenAPI · [kasanegi.com/en/api](https://kasanegi.com/en/api/) · [repository](https://github.com/MatsushitaTokitsugu/micro-data-api-factory-public)
- **Video production system** — AI writes, edits and publishes on its own

Research and development run on Claude Code. The main development repositories are private; this profile shows the public parts.
